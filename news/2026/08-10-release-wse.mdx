<Highlight color="#e06b74">Exclusive</Highlight> New **Archcraft Wayland Special Edition ISO** is now available to download. Read the changelogs below to know what's new. 

<!--truncate-->

This special edition of Archcraft comes with [`Sway`](/docs/wayland-compositors/sway), [`Wayfire`](/docs/wayland-compositors/wayfire), [`River`](/docs/wayland-compositors/river), [`Hyprland`](/docs/wayland-compositors/hyprland) and [`Newm`](/docs/wayland-compositors/newm) pre-installed, pre-configured and provides you a wayland only Linux experience.

### Changelogs :
**`Major Release`**
- Everything [Here](https://wiki.archcraft.io/news/63-news-release) , Plus...
- Updated all Exclusive Wayland Compositors
  - Updated scripts (alacritty, kitty, nm etc...)
  - Updated theme scripts, Firefox now follows the desktop theme correctly
  - Added few window rules
  - Client-side decorations disabled (create : `$HOME/.config/archcraft/disable-gtk-nocsd` to enable them)
  - Improved environment configuration
  - Updated waybar configs
  - Improved VirtualBox compatibility
  - `Sway` : Added `sov`
  - `Wayfire` : Updated configs to `v0.11.0`
  - `River` : Updated configs and scripts
  - `NEWM` : Updated configs and scripts
  - `Hyprland` : Migrated entire config to **LUA**, and updated it to `v0.56.2`
- Small improvements and bugs fixed.
