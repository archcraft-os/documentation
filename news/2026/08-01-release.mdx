<h1 align="center">Archcraft • August 2026 Release</h1>

> A release focused on stability, compatibility and polish. From a completely revamped installation experience to improved desktop sessions, better VirtualBox support and countless bug fixes, this is one of the biggest Archcraft updates yet.

![img](https://raw.githubusercontent.com/archcraft-os/.github/main/profile/assets/main.png)

---

## Highlights

- Brand new **Qt6 SDDM theme**
- New **Sway Wayland session**
- Reliable **encrypted installations** across installers
- Restored **Btrfs** and **XFS** installation support (calamares)
- Updated to **archiso 88-1**
- Improved VirtualBox compatibility
- Better GTK/GNOME application integration
- Hundreds of small fixes and improvements

---

## New Login Experience

Archcraft now ships with an all-new **Qt6-based SDDM theme**, bringing a cleaner design, improved HiDPI support and a more polished login experience.

![img](https://raw.githubusercontent.com/archcraft-os/misc-files/refs/heads/main/releases/august_2026/sddm.png)

---

## New Wayland Session

One of the biggest additions in this release is the introduction of **Sway**, providing another lightweight Wayland session alongside the existing window managers.

### Features

- Completely new appearance
- Carefully tuned defaults
- Improved VirtualBox compatibility
- Better GTK/GNOME application support
- Client-side decorations disabled for a more consistent desktop

> Added for HiDPI displays, wayland scales better on modern displays.

![img](https://raw.githubusercontent.com/archcraft-os/misc-files/refs/heads/main/releases/august_2026/sway.png)

> More Screenshots [Here](https://gallery.archcraft.io/pages/wcs/sway)

---

## Openbox Improvements

Openbox received numerous quality-of-life improvements.

### New

- Reload Theme option added to the menu
- Hot Corners powered by **Lead**
- Quick Window/Desktop switching using **Skippy-XD**
- Improved startup sequence
- Better GTK application integration
- Firefox and GNOME applications now follow the system theme correctly
- Improved Picom startup for VirtualBox

![gif](https://raw.githubusercontent.com/archcraft-os/misc-files/refs/heads/main/releases/august_2026/hot-corners.gif)

---

## BSPWM Improvements

The BSPWM session has also received several refinements.

### Improvements

- Replaced **feh** with **hsetroot**
- New network management menu
- Improved GTK application theming
- Client-side decorations disabled
- Better VirtualBox compatibility
- Improved Picom startup

## ABIF Installer

ABIF has become significantly more reliable.

### Fixed

- Encryption installation issues
- LVM installation crash
- Missing kernel parameters for systemd-boot
- systemd-boot installation
- GRUB EFI mounting

### Improvements

- Uses **sd-encrypt** hook
- Works correctly with encrypted and non-encrypted installations
- Better bootloader detection

### Tested Configurations

- Legacy BIOS
- Ext4
- Encryption
- Non-encryption
- LVM
- Non-LVM
- GRUB
- systemd-boot
