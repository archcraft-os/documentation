**Fedoracraft : Experience Archcraft on Fedora**

[![video](https://raw.githubusercontent.com/archcraft-os/misc-files/main/archcraftify/fedoracraft/main.gif)](https://youtu.be/uydoC4qNIFU)

## Overview

- Turns your Fedora into **Archcraft**
- Fully configured `openbox` window manager
- Fully configured `bspwm` window manager
- Fully configured `i3wm` window manager
- Multiple **themes/styles** for both (openbox and bspwm) WMs
- Everything else that Archcraft offers

:::warning
**Fedoracraft** is not an ISO or Fedora based distribution.
:::

**Fedoracraft** is an installable package that will turn your [Fedora](https://fedoraproject.org/) installation into Archcraft. Once installed on the top of Fedora, It'll offer everything Archcraft offers on your Fedora.

**Important** : Fedoracraft is created on the top of `Fedora Workstation 44` ISO (`Fedora-Workstation-Live-44-1.7.x86_64.iso`) and It's ***recommended*** that you install this on a fresh installation of Fedora Workstation 44.

### Installation

Follow the step below to install Fedoracraft :

- First, **Install Fedora Workstation 44**  on your computer
- Download the `fedoracraft_date.tar.gz` file from ko-fi (ex: `fedoracraft_2026-08-27.tar.gz`)
- Transfer or save the file on your Fedora installation
- Extract the file : `tar -xzvf fedoracraft_date.tar.gz`
- Change to extracted directory : `cd fedoracraft`
- Run install script and let it do it's job : `./install.sh`
- Once finished, _reboot your computer_ and you'll have **Fedoracraft installed**.
- If you want to remove gnome desktop and applications, you can run: `~/fedoracraft/remove-gnome.sh` after rebooting the system.

:::info[Video]
Watch the [complete installation video](https://youtu.be/uydoC4qNIFU)
:::

:::tip[Installation Logs]
**Installation Log** files (`fedoracraft_install_DATE.log`) are provided as well, you can review them to see how the script works.
:::
